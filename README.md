# YouTube Clone

A YouTube-inspired video website built with **HTML and CSS**. This project is a front-end web development practice project created to learn and demonstrate website structure, layouts, navigation, video cards, thumbnails, and responsive design.

## 📌 Project Overview

This project recreates the general layout and user interface of a video-sharing website.

The project focuses on:

* Website layout and structure
* Navigation bar
* Search bar
* Video thumbnails
* Video cards
* Video information
* Sidebar/navigation
* Responsive design
* HTML and CSS organization

> **Note:** This is a practice project inspired by YouTube. It is not affiliated with or owned by YouTube.

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the website.

You can also open the project in **Visual Studio Code** and use a browser such as Microsoft Edge or Chrome to preview it.
